Política de Privacidade

VO2 RunMax · Última atualização: maio de 2026

1. Controlador dos Dados

O aplicativo VO2 RunMax é o controlador dos dados pessoais coletados, nos termos da Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

2. Dados Coletados

  • Dados de cadastro: nome e endereço de e-mail, fornecidos voluntariamente ao criar uma conta.
  • Dados de uso: resultados dos testes físicos (VO2máx estimado, distâncias, tempos) e planilhas salvas.
  • Dados técnicos: preferências de interface armazenadas localmente no navegador (localStorage).

3. Finalidade do Tratamento

  • Salvar e sincronizar planilhas de treino entre dispositivos.
  • Personalizar a experiência do usuário dentro do app.
  • Melhorar o serviço com base no uso agregado e anônimo.

4. Base Legal

O tratamento de dados é baseado no consentimento do titular (Art. 7º, I, LGPD) e na execução do contrato de uso do serviço (Art. 7º, V, LGPD).

5. Compartilhamento de Dados

Os dados são armazenados no Firebase (Google), serviço com certificação de segurança internacional. Não vendemos, alugamos ou compartilhamos seus dados com terceiros para fins comerciais.

6. Seus Direitos (LGPD)

Como titular, você tem direito a:

  • Confirmar a existência de tratamento dos seus dados
  • Acessar, corrigir ou atualizar seus dados
  • Solicitar a exclusão dos dados (direito ao esquecimento)
  • Revogar o consentimento a qualquer momento
  • Portabilidade dos dados

Para exercer esses direitos, entre em contato pelo e-mail de suporte, ou use a opção "Excluir conta" diretamente dentro do app.

7. Cookies e Armazenamento Local

Utilizamos localStorage do navegador para salvar preferências como onboarding concluído e aceite desta política. Não utilizamos cookies de rastreamento ou publicidade.

8. Retenção de Dados

Os dados são mantidos enquanto a conta estiver ativa. Ao solicitar exclusão da conta, todos os dados associados serão removidos em até 30 dias.

9. Segurança

Adotamos medidas técnicas e organizacionais adequadas para proteger seus dados contra acesso não autorizado, perda ou destruição, incluindo autenticação segura via Firebase Auth.

10. Integrações de Terceiros

O app oferece integração opcional com o Intervals.icu, mediante configuração voluntária de uma chave de API pelo próprio usuário, para importar automaticamente dados de treinos realizados. Essa integração pode ser desconectada a qualquer momento nas configurações do app.
